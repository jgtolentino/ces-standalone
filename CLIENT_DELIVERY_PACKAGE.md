## 🚀 Quick Start Instructions

### 1. Access the Code
```bash
git clone -b scout-v3.1.0-client-delivery https://github.com/jgtolentino/ces-standalone.git
cd ces-standalone
```

### 2. Install & Build
```bash
npm install
npm run build
```

### 3. Configure Environment
Create `.env.local` with your Azure credentials (see Deployment Guide)

- **Option A**: One-click Vercel deploy (recommended)
- **Option B**: Manual deployment to your infrastructure
- **Option C**: Docker containerization
