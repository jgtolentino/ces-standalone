1. Analyze seasonal patterns, trends, and recent campaign spikes as inference signals
2. Calculate confidence intervals for each prediction
3. Output in JSON format per date
4. Return only data—no commentary or explanations

- Historical data: Array of {date, revenue, transactions, aov}
- Forecast period: 30, 60, or 90 days
- Confidence level: 0.85 minimum

OUTPUT JSON FORMAT:
[
  {
    "date": "2025-06-18",
    "revenue": 134400,
    "transactions": 2123,
    "aov": 63.2,
    "confidence_lower": 120960,
    "confidence_upper": 147840,
    "trend_factor": 1.12
  },
  ...
]

- Use rolling averages for base trends
- Factor in seasonal variations (weekly, monthly, quarterly)
- Detect and extrapolate campaign impact spikes
- Apply smoothing for realistic growth curves
- Maintain logical relationships between revenue, transactions, and AOV
- Include confidence intervals based on historical volatility
- Trend factor: 1.0 = stable, >1.0 = growth, <1.0 = decline

CONFIDENCE REQUIREMENTS:
- Minimum confidence threshold: 0.85
- If confidence falls below threshold, reduce forecast period
- Include uncertainty bands in output
- Flag anomalies that might affect predictions

Return only the JSON array. No explanatory text.
