## 🏗️ Architecture Overview

The CES Dashboard implements a hybrid scoring methodology combining:

- **Automated Features**: Sentiment polarity, performance scores, emotional intensity
- **Human Creative Features**: Visual distinctiveness, cultural relevance, message clarity
- **Interaction Effects**: Emotional × Cultural (1.27 weight), Message × CTA (0.247), Visual × Brand (0.225)

## 🎮 Step-by-Step Tutorial

### Step 1: Overview Dashboard
Navigate to `/ces/overview` to see:
- **KPI Cards**: Brand recall, persuasion, fluency, brand lift scores
- **Portfolio Radar**: Performance across creative features
- **Campaign Phases**: Distribution across briefing, development, activation
- **AI Insights**: Automated findings and recommendations

### Step 2: Creative Scorecard
Visit `/ces/scorecard` for deep-dive analysis:
- **Asset Selection**: Choose from video, static, audio creative assets
- **SHAP Analysis**: Feature importance with positive/negative impact
- **Timeline View**: Frame-by-frame video analysis
- **AI Recommendations**: Specific improvement suggestions

### Step 3: Ask CES Prompt Interface
Use `/ces/prompts` for natural language queries:
```
Example prompts:
- "Optimize this campaign for Gen Z audience"
- "Analyze emotional impact and suggest improvements"
- "Compare performance against top performers"
- "Predict campaign success based on creative features"
```

### Step 4: AI Model Insights
Explore `/ces/insights` to understand:
- **Global SHAP**: What drives effectiveness across all campaigns
- **Model Versions**: Track improvements and feature changes
- **Confidence Zones**: Reliability bands by prediction accuracy
- **Feature Distribution**: Usage patterns across campaigns

### Step 5: Segment Analysis
Analyze `/ces/segments` for demographic insights:
- **Regional Map**: Performance by Philippines regions
- **Demographic Matrix**: Age × Gender effectiveness breakdown
- **Persona Cards**: Top-performing audience segments
- **Trend Analysis**: Performance changes over time

## 🔧 Technical Implementation

### Components Architecture
```typescript
// Core components following YAML spec
- CreativeScoreCard: Displays metrics with trends
- RadarChart: Multi-dimensional performance view
- SHAPChart: Feature importance visualization
- PromptPanel: Natural language input interface
- CESChat: AI conversation interface
```

### State Management
```typescript
// Zustand global state
const { campaigns, filters, chatMessages } = useCESStore()

// Global filters applied across all pages
- campaign, format, creative_phase, region, segment, date_range
```

### API Integration
```typescript
// CES scoring endpoints
POST /api/ces/score     // Calculate effectiveness score
POST /api/ces/chat      // AI chat responses
GET /api/ces/insights   // Model explanations
GET /api/ces/segments   // Demographic data
```

## 🆘 Troubleshooting

### Common Issues

**Issue**: Pages not loading  
**Solution**: Check Next.js routing configuration in `app/ces/*/page.tsx`

**Issue**: SHAP charts not rendering  
**Solution**: Verify Recharts dependency and data format

**Issue**: AI chat not responding  
**Solution**: Check API endpoints and prompt processing logic

**Issue**: Filters not persisting  
**Solution**: Validate Zustand store configuration
